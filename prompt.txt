Using the different mock-ups attached, create a project that basically allows one connect property owners to people who want to get properties to rent or buy. The system has to work in a way that the person who wants to rent or buy a given property has to go through the broker who is the one using this site so that they can reach the real property owner. This is based off a Ugandan setting.  The website manages hostels and rental houses. The admin can upload different details about a given property such as images, videos, area/location, pricing and description. The admin has a dashboard where they can adjust different objects on the site like editing different elements and features. They can also be able to remove properties that have already been taken. On the site, visitors can search, view different properties and also view ratings. The site also has filters regarding prices, location, number of rooms and ratings. Suggest a suitable name and logo.
