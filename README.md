# Lyton PHP MVC Project

A standard PHP MVC project scaffold using Composer autoloading.

## Structure

- `app/` - MVC application code
- `app/Controllers/` - controller classes
- `app/Models/` - data models
- `app/Views/` - view templates
- `app/Core/` - framework core classes
- `config/` - configuration files
- `public/` - web root
- `vendor/` - Composer packages (generated)

## Usage

1. Run `composer install`
2. Point your web server document root to `public/`
3. Open the app in your browser
